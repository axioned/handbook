## Creating Your GitHub Account

If you don't already have a GitHub account for Axioned, create one at [github.com](https://github.com/signup).

### Username

Use the following format: **first letter of your last name + first name + "axioned"**

| Name | Username |
|---|---|
| Anurag Banerjee | `banuragaxioned` |
| Jane Smith | `sjaneaxioned` |

> All lowercase, no spaces or special characters.

### Email

Register with your Axioned email address (`yourname@axioned.com`).

## Enable Two-Factor Authentication (2FA)

2FA is **mandatory** for all Axioned GitHub accounts.

Go to **Settings → Password and authentication → Two-factor authentication** and enable it.

### Recommended authenticator apps

Use an authenticator app that **syncs across devices** so you don't lose access if you change or lose your phone.

:::caution[Avoid Google Authenticator]
We recommend **against** Google Authenticator. It does not sync across devices — if you lose your phone and don't have your backup codes stored safely, you will lose access to your account permanently.
:::

**Recommended alternatives:**

- [**1Password**](https://1password.com/) — syncs across devices, works as both a password manager and TOTP authenticator
- [**Authy**](https://authy.com/) — free, syncs across devices with encrypted backups
- [**Bitwarden**](https://bitwarden.com/) — open-source, syncs across devices, built-in TOTP support (premium)

### Save your backup codes

GitHub will generate backup codes during 2FA setup. **Store these somewhere safe** (e.g. your password manager or a secure note). These are your recovery option if you ever lose access to your authenticator.

## Joining the Axioned GitHub Organisation

Once your account is set up, let your team lead or IT admin know your GitHub username. You'll be sent an invitation to join the [**Axioned GitHub organisation**](https://github.com/axioned).

Accept the invitation via email or by visiting [github.com/axioned](https://github.com/axioned).
